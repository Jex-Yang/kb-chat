# KBChat 知识库网页聊天工具 · PRD v1.0
> 历史文档（2026-10-27 的任务/交付记录）。当前实现、部署与已知变更见 README.md 与 docs/ARCHITECTURE.md §0。

## 1. 产品目标
- 定位：单机部署的企业级观感知识库网页聊天工具，本地文件入库 + 轻量 RAG 检索 + 多轮流式对话。
- 目标用户：需要在本地管理文档并用 LLM 问答的个人/小团队知识工作者。
- 核心价值：文件即语料，开箱即用，无需登录、无需向量数据库。
- 成功指标（验收口径）：上传 1 个 ≤10MB 的 PDF 后 10 秒内完成入库并可检索命中；检索接口 P95 ≤ 200ms（10MB 语料内）；流式输出首 token 到达 ≤ 3s（上游正常时）。

## 2. 非目标（本期不做）
- 不做用户登录体系、账号、角色权限。
- 不做向量数据库 / Embedding 模型（仅分词倒排 + 字符级评分）。
- 不做并发多用户隔离（单浏览器单工作区）。
- 不做移动端适配（桌面 ≥1280px 优先）。
- 不做文件在线编辑。

## 4. 需求池（P0:11 / P1:4 / P2:3，共 18 条）
### P0（MVP 核心闭环）
| ID | 需求 | 验收标准 |
|----|------|----------|
| FR-01 | 深色主题三栏布局，仿 DeepSeek 官网 | ≥1280px 下无横向滚动条；侧边栏可收起（宽度 260px→0，带过渡动画 ≤300ms） |
| FR-02 | 侧边栏知识库区：目录树 | 支持新建目录/子目录（层级 ≤3）、删除（有文件时二次确认）、选中高亮 |
| FR-03 | 文件上传入库 | 支持 txt/md/csv/pdf/docx/xlsx；>20MB 拒绝并提示；解析失败显示明确错误；成功后文件出现在对应目录 |
| FR-04 | 文本分块索引 | 按 ≤500 token 分块、相邻块 50 token 重叠；入库后立即可检索 |
| FR-05 | 轻量 RAG 检索 | 内存倒排 + 字符级评分，Top-5 片段注入 system/上下文；检索 P95 ≤200ms（≤10MB 语料） |
| FR-06 | 对话管理 | 新建/切换/重命名/删除对话；删除需确认；切换后消息完整恢复 |
| FR-07 | 多轮上下文 | 携带最近 ≤20 条消息（可配置）请求上游 |
| FR-08 | 流式输出 | SSE 逐字渲染；中断/停止按钮可终止生成 |
| FR-09 | 思维链展示 | "已深度思考（用时 X 秒）"折叠条，默认折叠，点击展开推理文本；X 为实测秒数取整 |
| FR-10 | 思考深度设置 | 关闭/low/high/max 四档，默认 high；切换立即对下次请求生效；映射至上游 reasoning 参数（假设：商汤上游用 `thinking.enabled/budget_tokens`，映射表在技术方案定稿） |
| FR-11 | 自定义 API 设置 | base URL / API Key / 模型名可在设置弹窗修改并持久化 localStorage；默认：`https://token.sensenova.cn/v1`、模型 `deepseek-flash`、Key 留空 |
| FR-12 | 429 自动重试 | 指数退避（1s/2s/4s，最多 3 次）；仍失败则在消息气泡内显示"上游限流，已重试 3 次" |
| FR-13 | Token 计量 | 默认配额 1,000,000；侧边栏显示 已用/剩余/百分比 + 进度条；从响应 usage 字段累加；精确到 1 token |
| FR-14 | 知识库导入/导出 | 导出为单个 JSON（含目录/文件/分块/索引）；导入全量替换且成功后重建索引；导出文件可再次导入校验一致 |

## 5. 页面清单与状态
| 页面/区块 | 核心内容 | 状态 |
|-----------|----------|------|
| 主聊天区 | 消息流、输入框、发送/停止按钮 | 空态（引导文案）/生成中/完成/错误 |
| 侧边栏-知识库 | 目录树 + 上传按钮 | 空库态/加载态/文件上传中 |
| 侧边栏-对话列表 | 对话条目（重命名/删除入口）+ 新建按钮 | 空态/选中态 |
| 侧边栏-底部 | Token 用量进度条 | 正常（<80%）/告警（≥80% 变橙）/耗尽（100% 变红，仍可发但提示） |
| 设置弹窗 | base URL / Key / 模型名 / 思考深度 / 上下文条数 | 打开/保存成功/保存失败 |

主流程：选目录 → 上传文件 → 解析分块入库 → 新建对话 → 提问 → 检索 Top-5 注入 → 流式回答 + 思维链 → usage 累加至计量条。

## 6. 数据实体表
| 实体 | 字段 | 类型 | 必填 | 约束/默认值 |
|------|------|------|------|-------------|
| folder | id, name, parent_id, created_at | string, string, string\|null, ISO8601 | 是 | id=uuid；层级 ≤3 |
| file | id, folder_id, name, type, size_bytes, status, created_at | 同上 | 是 | type ∈ {txt,md,csv,pdf,docx,xlsx}；size ≤ 20MB；status ∈ {uploading,parsing,ready,failed} |
| chunk | id, file_id, seq, content, tokens | string… | 是 | content ≤500 token；seq 从 0 递增；tokens 为整数 |
| conversation | id, title, created_at, updated_at | 同上 | 是 | title 默认"新对话"，重命名 ≤50 字符 |
| message | id, conversation_id, role, content, reasoning, reasoning_seconds, usage_tokens, created_at | 同上 | 是 | role ∈ {user,assistant,system}；usage_tokens 默认 0 |
| usage | total_quota, used_tokens | int | 是 | total_quota=1000000；used 只增不减 |
| settings | base_url, api_key, model, thinking_level, context_limit | string… | 是 | 默认见 FR-11/FR-10；thinking_level ∈ {off,low,high,max}；context_limit 默认 20 |

## 7. 非功能需求
| 项 | 指标 | 验证方式 |
|----|------|----------|
| 检索性能 | P95 ≤200ms（10MB 语料） | 本地基准脚本压测 |
| 上传解析 | ≤10MB 文件 ≤10s 完成 status=ready | 手动用例计时 |
| 流式首 token | ≤3s（上游正常） | 抓包计时 |
| 兼容 | Chrome/Edge 最近两个大版本，≥1280px | 手动回归 |
| 安全 | API Key 仅存 localStorage，不落服务端日志 | 代码审查 |
